# MindMitra Three-Minute Pitch

MindMitra helps people living with memory difficulties stay connected to familiar people, places, and routines.

The platform is calm rather than overwhelming. A patient sees large, clear choices for memories, games, reminders, and talking with the app. A caregiver has one workspace for reminders, memories, progress, and uploads.

The memory map turns life stories into a constellation: each relationship is a thread and every memory is a star. The same view can become a simple patient experience or a caregiver editing experience.

MindMitra uses caregiver-supplied facts. It never invents memories, diagnoses conditions, or gives medical predictions. Voice has a typed alternative, Calm Mode respects individual preferences, and patient controls use accessible targets.

The demo is built with Flask and SQLAlchemy, with a SQLite local database and an upload adapter that can move to S3 later. AWS architecture is documented but not automatically provisioned.

MindMitra does not replace family, caregivers, or professional care. It gives them a gentler way to support familiarity and engagement.
